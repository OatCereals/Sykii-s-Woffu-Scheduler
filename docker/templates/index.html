Woffu access

Prefer environment variables WOFFU_USERNAME / WOFFU_PASSWORD. If you save them here, they are written to data/secrets.json on disk (plain text).

Quick shifts

Paint mode: OFF Rest Click a shift (or Rest) to paint. Then click days on the calendar. Click a day again to clear it.

Jitter: punch anywhere from 0:00 to N:00 after the shift (e.g. 4 → 07:50:00 … 07:54:00, including 07:52:13). Same day always gets the same time. 0 = exact time.

Gold dot = holiday (you can still punch it). Teal border = day with a shift. The app must be running for it to punch at each shift time.
